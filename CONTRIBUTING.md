# Contributions Guidelines

This repository is a research learning laboratory. We welcome contributions that enhance the learning journey and research quality.

## Before Contributing

- Understand the learning progression model (mathematics → ML → DL → vision → robotics → etc.)
- Ensure implementations are from-scratch before using libraries (where applicable)
- All code should have type hints, docstrings, and tests
- No placeholder or fake implementations

## Code Quality

- Type hints on all functions and classes
- Comprehensive docstrings (Google or NumPy style)
- Unit tests for all modules
- Modular, reusable code
- Follow PEP 8 style guidelines

## Reporting Issues

- Clearly describe bugs with reproducibility steps
- Suggest improvements with clear motivation
- Reference related papers or research

## Commit Messages

- Clear, descriptive commit messages
- Reference issue numbers when applicable
- Include "Co-authored-by" trailers for collaboration

## Research Integrity

- Do NOT create fake research results
- Do NOT include placeholder implementations pretending to be complete
- Mark incomplete work as TODO
- Document experimental methodology clearly
- Save reproducible results with configuration

Thank you for contributing to the research lab!
